# Highstack Website

The rebuild of [highstack.ca](https://highstack.ca).

Highstack is a quiet parent company that creates, owns, and operates focused businesses across health, editorial, consulting, and personal finance.

## Stack

- **Astro 5** — static export to `dist/`, deployed to GitHub Pages.
- **MDX** — operator notes.
- **React 19 islands** — only for interactive bits (contact form, mobile drawer).
- **Vanilla CSS** with tokens from the Highstack design system.
- **Biome** for lint + format.

## Local development

```bash
nvm use         # Node 20
npm install
npm run dev     # http://localhost:4321
npm run build   # outputs to ./dist
npm run preview # serves the built site
npm run lint    # biome lint
npm run format  # biome format --write
```

## Branch model

| Branch | Purpose |
|---|---|
| `main` | Production. Currently serves the legacy site until cutover. |
| `rebuild` | This rebuild, in progress. Renamed to `dev` at cutover. |
| `archive/dev-pre-rebuild` | Snapshot of the previous Next.js rebuild attempt (preserved). |
| `gh-pages` | Auto-generated by CI from `main`. Do not edit. |

## Design system

The complete design system lives in `design-system/` (gitignored — handoff reference only).

- Brand foundations + voice: `design-system/highstack-design-system/project/README.md`
- Locked decisions: `design-system/highstack-design-system/project/CLAUDE.md`
- Tokens: `design-system/highstack-design-system/project/colors_and_type.css` (ported to `src/styles/tokens.css`)

A condensed agent-facing version lives in `CLAUDE.md` at the project root.

## Project layout

```
src/
  pages/                 Astro pages (file-based routing)
  layouts/               BaseLayout
  components/            Astro components
  components/islands/    React islands (interactive only)
  content/               Astro content collections (portfolio, notes)
  styles/                tokens.css + site.css
public/
  brand/                 Wordmarks, needle variants, favicons
  CNAME                  highstack.ca
```

## Brand at a glance

- **Yellow** `#F9C219` — the page surface, not an accent.
- **Ink** `#0A0A0A` — type and primary buttons.
- **Paper** `#F6F3EC` — long-form editorial sections.
- **Type:** Newsreader (display + headline) · Geist (UI + body) · Geist Mono (data).
