# Highstack Website

The rebuild of [highstack.ca](https://highstack.ca), built with Next.js 14 and exported as a static site to GitHub Pages.

## Tech stack

- **Framework:** Next.js 14 (App Router, static export via `output: 'export'`)
- **Styling:** Tailwind CSS v3
- **Animations:** Framer Motion
- **Forms:** Formspree (`@formspree/react`)
- **Content:** MDX (`next-mdx-remote` + `gray-matter`)
- **Deployment:** GitHub Actions → `gh-pages` branch → GitHub Pages
- **Domain:** highstack.ca (CNAME)

## Branch model

| Branch | Purpose |
|--------|---------|
| `main` | Production until cutover. Currently serves the legacy static site. |
| `dev`  | Active development of the rebuild. Merge into `main` only when ready to go live. |
| `gh-pages` | Auto-generated by CI from `main` once cutover happens. Do not edit. |

## Local development

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # produces ./out
```

## Project structure

```
app/                 Next.js App Router pages, layouts, globals.css
components/          Reusable UI components
data/                Typed content collections (team, services, testimonials, ...)
content/blog/        MDX blog posts
public/              Static assets (logos, favicons, CNAME)
public/assets/       Highstack brand assets (logos, needle marks)
archive/             Legacy WIP pages from before the rebuild
```

## Brand

- **Yellow:** `#F5C000`
- **Ink:** `#1C1C2E`
- **Off-white:** `#F5F4F0`
- **Type:** Outfit (Google Fonts, variable weight)
